Спортивний трекер (Fitness & Diet Tracker)

Опис проєкту
Ця програма допомагає відстежувати фізичну активність та харчування. Вона підходить для різних цілей та дозволяє планувати тренування (спліти верх/низ, фулбоді).

 Основні можливості (що планується реалізувати):
- Створення профілю користувача з розрахунком норми калорій.
- Додавання тренувань та збереження програм.
- Трекінг харчування та вітамінів/добавок.
- Виведення статистики та прогресу.

 Архітектура ООП (базовий план):
Проєкт буде демонструвати базові принципи ООП (інкапсуляція, успадкування, поліморфізм).
- Класи: User, Goal, DietPlan, FoodItem, Supplement, WorkoutProgram.
- Ієрархія (успадкування):** Базовий клас `Activity`, від якого успадковуються `StrengthTraining` (силове тренування) та `Cardio` (кардіо). 
- Поліморфізм: Віртуальний метод `calculateCaloriesBurned()` у класі `Activity`, який буде мати різну реалізацію для силових та кардіо тренувань.
